# Игра "Угадай загаданное число"
**Суть игры:** на уровне кода загадывается случайное целое число в промежутке [1; 100]. Задача пользователя - угадать загаданное число. После каждой неудачной попытки пользователь получает подсказку о том, больше или меньше загаданное число относительно введённого.

**Требования:**
- Python 3
- Для генерации случайного числа используется функция `randint` из стандартного модуля `random`.
- Дополнительные библиотеки не требуются.
### Структура
Программа разделена на несколько функций, каждая из которых отвечает за отдельную часть логики:
- `greetings()` - приветствует пользователя и выводит правила игры.
- `get_integer(text)` - запрашивает у пользователя целое число и проверяет корректность ввода (проверка на дурака).
- `get_attempt_form(number)` - выбирает правильную форму слова "попытка" в зависимости от количества совершённых попыток.
- `game()` - содержит основную логику одной игровой партии.
- Блок `if __name__ == '__main__':` точка входа в программу. Запускает приветствие, игровые партии и обрабатывает предложение сыграть повторно.
### Моментные реализации некоторых фич

`get_integer` — функция отвечает за получение и валидацию пользовательского ввода.

Ввод сначала очищается от пробелов с помощью `strip()`, после чего выполняется попытка преобразования строки в `int`. Если преобразование невозможно, перехватывается исключение `ValueError`, пользователю выводится сообщение об ошибке, после чего ввод повторяется.

Дополнительно проверяется принадлежность полученного числа диапазону [1; 100]. Число возвращается из функции только после прохождения обеих проверок.

---

`correct_attempt_form_selection` - функция реализует выбор правильной формы слова "попытка":
- `1 попытКА`;
- `2-4 попытКИ`;
- `5-20 попытОК`;
- `21 попытКА`;
- `22–24 попытКИ`;
- ...

Для определения формы используются остатки от деления на 10 и 100. Отдельно обрабатываются числа, оканчивающиеся на 11-14, для которых всегда используется форма `попытОК`.

---

`game` — функция реализует одну игровую партию.

В начале партии с помощью `randint(1, 100)` генерируется случайное целое число. После этого пользователь вводит свои предположения до тех пор, пока введённое число не совпадёт с загаданным.

После каждой неудачной попытки программа сообщает:
- `Загаданное число меньше!`, если пользователь ввёл слишком большое число;
- `Загаданное число больше!`, если пользователь ввёл слишком маленькое число.

Одновременно ведётся подсчёт количества попыток. После победы выводятся загаданное число и итоговое количество попыток с правильной формой слова "попытка".

---

После завершения партии пользователь может выбрать дальнейшее действие:
- `y` — начать новую партию;
- `n` — завершить программу.

Любой другой ввод отклоняется, после чего программа повторно запрашивает `y` или `n`.

Повторные партии реализованы с помощью циклов `while`, без рекурсивного вызова `game()`.
