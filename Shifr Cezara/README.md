# **Программа «Шифр Цезаря»**
> При разработке я старался делать функции самостоятельными. Каждая решает отдельную задачу и по возможности может использоваться независимо от остальной программы.

Суть программы: шифрование и расшифровка текста методом Цезаря. Пользователь выбирает алфавит, вводит величину сдвига и текст, когда как программа заменяет каждую букву на другую букву того же алфавита.
При шифровании буквы сдвигаются вперёд, при расшифровке - назад. Если сдвиг выходит за конец алфавита, отсчёт продолжается с его начала.

```text
Алфавит:           abcdefghijklmnopqrstuvwxyz
Исходный текст:    Hello, World!
Сдвиг:             3
Результат:         Khoor, Zruog!
```

Программа сохраняет регистр букв, пробелы и поддерживаемые знаки пунктуации. Для работы доступны три готовых алфавита: русский без "ё", русский с "ё" и английский. Свои алфавиты можно добавлять, изменять и удалять через отдельное меню.

## Требования
- Python 3.10 или новее.
- Сторонние библиотеки не требуются: программа использует стандартную библиотеку Python.
- Перед первым запуском нужно создать базу данных с алфавитами.

## **Быстрый запуск**
Откройте терминал в папке проекта и выполните:

```bash
python --version
python dbInit.py
python main.py
```

`dbInit.py` создаст файл `languages.db` и добавит в него три готовых алфавита. После этого откроется главное меню программы.

> **Важно:** `dbInit.py` удаляет существующую таблицу языков и создаёт её заново. Если запустить этот файл повторно, добавленные и изменённые вами алфавиты будут потеряны.

Для следующих запусков достаточно команды `python main.py`.

После одного шифрования или расшифровки программа завершается. Чтобы обработать ещё один текст, запустите `main.py` снова.

## Как пользоваться
### Шифрование
1. В главном меню выберите `1. Зашифровать`.
2. Выберите алфавит из списка.
3. Введите положительное целое число - величину сдвига.
4. Введите текст, написанный с использованием выбранного алфавита.

Например, для английского алфавита и сдвига `3`:

```text
Выбор действия:  1
Выбор алфавита:  3 - English
Сдвиг:           3
Текст:           Hello, World!

Результат: Khoor, Zruog!
```

### Расшифровка
Выберите `2. Расшифровать`, затем тот же алфавит и ту же величину сдвига, которые использовались при шифровании:

```text
Выбор действия:  2
Выбор алфавита:  3 - English
Сдвиг:           3
Текст:           Khoor, Zruog!

Результат: Hello, World!
```

Порядковый номер алфавита может измениться, если вы добавляли или удаляли записи. Ориентируйтесь на список, который выводит программа.

### Настройка алфавитов
В меню выбора алфавита есть пункт "Настроить языки...". Он открывает отдельное меню, в котором можно:
- добавить алфавит и его название;
- удалить алфавит;
- изменить название или последовательность букв существующего алфавита.

Настройщик также можно запустить отдельно:

```bash
python languageConfigurator.py
```

При добавлении нового алфавита каждый его символ должен быть уникальным без учёта регистра. Порядок символов имеет значение: именно по нему программа выполняет сдвиг. Например, для алфавита `abcde` при сдвиге `1` буква `e` превратится в `a`.

| Файл | Назначение |
| --- | --- |
| `main.py` | Показывает главное меню, предлагает выбрать алфавит, проверяет текст и выполняет шифрование или расшифровку. |
| `languageConfigurator.py` | Работает с записями алфавитов в базе данных: добавляет, удаляет и изменяет их. |

## Моментные реализации некоторых фич
### Сдвиг по кругу
Чтобы после последней буквы снова перейти к первой, используется остаток от деления на длину алфавита. В коде шифрование и расшифровка различаются знаком перед сдвигом:

```python
# Шифрование
new_index = (current_index + shift) % len(alphabet)

# Расшифровка
new_index = (current_index - shift) % len(alphabet)
```

Такой подход работает и при сдвиге больше длины алфавита.

### Сохранение регистра и знаков
Для прописных и строчных букв используются соответствующие варианты выбранного алфавита. Поэтому `H` остаётся прописной буквой, а `e` - строчной.

Пробельные символы, знаки из `string.punctuation`, а также `«`, `»`, `—` и `…` выводятся без изменения:

```text
Hello, World!  →  Khoor, Zruog!
```

### Проверка текста перед обработкой
Перед шифрованием или расшифровкой программа проверяет каждый символ. Если символ не входит в выбранный алфавит и не относится к разрешённым знакам или пробелам, программа сообщает об ошибке и просит ввести текст заново.

Например, при выборе английского алфавита русские буквы не пройдут проверку. Цифры тоже не пройдут её, если они не добавлены в пользовательский алфавит.

### Хранение алфавитов
Название и последовательность символов каждого алфавита хранятся в таблице SQLite `languages`. Готовые записи создаются скриптом `dbInit.py`:

```text
1. Русский без Ё
2. Русский с Ё
3. English
```

При добавлении алфавита программа проверяет, что его символы не повторяются без учёта регистра. После удаления алфавита ID следующих записей пересчитываются.

## **Текущие ограничения**
- Главное меню выполняет одну операцию за запуск.
- Поддерживается только положительная величина сдвига; для обратного преобразования предусмотрен отдельный пункт «Расшифровать».
- Текст должен соответствовать одному выбранному алфавиту. Смешанный русский и английский текст не обработается, если оба набора букв не включены в пользовательский алфавит.
- При изменении существующего алфавита проверка на повторяющиеся символы не выполняется. При добавлении нового алфавита она есть.
- Пустая строка принимается как текст и даёт пустой результат.
