# Игра "Магический шар 8"
**Суть программы:** пользователь вводит своё имя и задаёт произвольный вопрос, после чего программа случайным образом выбирает одну из категорий ответов и выводит случайную фразу из этой категории.

Имя пользователя сохраняется в файл `name.txt`, поэтому при следующем запуске программа может использовать его повторно. Перед продолжением пользователь подтверждает сохранённое имя и при необходимости может изменить его.

**Требования:**
- Python 3
- Встроенные модули `random`, `json`, `pathlib`
- Дополнительные библиотеки не требуются.
### Структура
Программа разделена на несколько функций:
- `get_name()` - получает имя пользователя, удаляет лишние пробелы по краям и не допускает пустой ввод.
- `confirm_name()` - предлагает пользователю подтвердить сохранённое или введённое имя и позволяет изменить его.
- `load_data()` - загружает фразы из `phrases.json`, считывает имя из `name.txt` или создаёт его при первом запуске.
- `main()` - содержит основную логику программы: приветствие пользователя, получение вопроса, выбор случайного ответа.

Для работы программы рядом с исполняемым `.py`-файлом должен находиться файл `phrases.json`.

`name.txt` создаётся автоматически после первого запуска программы.

```
Magic 8 Ball/
├── main.py
├── phrases.json
└── name.txt
```

### Моментные реализации некоторых фич
##### Работа с путями
Пути к `phrases.json` и `name.txt` определяются относительно директории самого Python-файла:

```python
current_dir = pathlib.Path(__file__).parent
```

Благодаря этому программа не зависит от текущей рабочей директории (CWD) и корректно находит необходимые файлы даже при запуске из другой директории.
##### Работа с кодировкой
При чтении и записи текстовых файлов явно используется UTF-8:

```python
read_text(encoding='utf-8')
write_text(..., encoding='utf-8')
```

Это позволяет избежать зависимости от системной кодировки, в частности на Windows.
##### Сохранение имени пользователя
При первом запуске программа запрашивает имя пользователя и сохраняет его в `name.txt`.

При следующих запусках сохранённое имя считывается из файла и предлагается пользователю для подтверждения:

```bash
Вас зовут X? (y/n):
```

Если имя указано неверно, пользователь может ввести новое значение.
##### Проверка пользовательского ввода
Имя очищается от пробелов методом `.strip()` и проверяется на пустоту:

```python
while not name:
    print('Имя не может быть пустым!\n')
    name = input(text).strip()
```

Таким образом, пустая строка или строка, содержащая только пробелы, не принимается.

При подтверждении имени принимаются только значения `y` и `n`. Ввод предварительно нормализуется `.strip().lower()`.
##### Хранение ответов
Ответы магического шара хранятся отдельно от исходного кода в файле `phrases.json`.

Это позволяет изменять или дополнять набор фраз без изменения Python-кода программы.

Программа сначала случайным образом выбирает категорию, а затем случайную фразу внутри выбранной категории:

```python
category = phrases[random.choice(list(phrases))]
answer = random.choice(category)
```

Количество фраз в категории при этом не зафиксировано в исходном коде.
##### Точка входа
Запуск основной логики программы выполняется через стандартную конструкцию:

```
if __name__ == '__main__':
    main()
```

Благодаря этому файл можно как запускать напрямую, так и импортировать как модуль без автоматического выполнения `main()`.
### Проблемы, с которыми пришлось столкнуться
1. проблема чтения файла с именем на разных ОС, т.к. Windows по умолчанию может записывать в кодировке cp1251. решение - четкое указание кодировки.
2. del для оптимизации имеет смысл использовать только с большими объектами, которые не используются кодом далее. в ином случае почти никакого эффекта не будет, а читаемость кода ухудшится.
3. запуская программу, необходимые файлы могут создаться в CWD, если запущена не из директории самого файла. по умолчанию относительные пути делаются из CWD. решение - передавать перед относительным путем путь папки, в которой находится исполняемый файл.
