# Программа "Генератор псевдослучайных паролей"
**Суть программы:** генерация паролей заданной длины из выбранных пользователем категорий символов.

Доступные категории:
- строчные латинские буквы
- заглавные латинские буквы
- специальные символы
- цифры

**Требования:**
1. Python 3.9 и новее
2. Стандартная библиотека Python
### Структура
Основная логика программы разделена на две части.

##### `generate()`
Функция отвечает непосредственно за генерацию пароля. Она принимает следующие параметры:

```python
generate(
    lowercase: bool,
    uppercase: bool,
    punctuation: bool,
    digits: bool,
    length: int,
) -> str
```

Параметры определяют:
- `lowercase` - разрешены ли строчные буквы
- `uppercase` - разрешены ли заглавные буквы
- `punctuation` - разрешены ли специальные символы
- `digits` - разрешены ли цифры
- `length` - длина генерируемого пароля

Функция самостоятельно проверяет корректность переданных данных.
Если не выбрана ни одна категория символов или длина пароля меньше или равна нулю, вызывается исключение `ValueError`.
##### `get_password_options()`
Функция отвечает за взаимодействие с пользователем через консоль.

1. выводит список доступных категорий символов
2. получает выбор пользователя
3. проверяет корректность введённых категорий
4. запрашивает длину пароля
5. проверяет, что длина является положительным целым числом
6. возвращает полученные настройки генерации
##### Точка входа

Основной код программы запускается только при непосредственном запуске файла. Это позволяет импортировать функцию `generate()` в другие Python-модули или тесты без запуска в консоли:

```python
if __name__ == '__main__':
```
### Моментные реализации некоторых фич
##### Выбор нескольких категорий
Категории вводятся одной строкой. Порядок цифр не имеет значения. Повторное указание одной категории также не изменяет результат.

##### Проверка выбранных категорий
Программа разрешает вводить только цифры от `1` до `4`. Также строка не может быть пустой. 
Иначе программа попросит повторить ввод.
### Проверка длины
Длина пароля должна быть положительным целым числом.
При некорректном вводе программа повторно запрашивает длину.
##### Формирование набора символов
Для получения наборов символов используется стандартный модуль `string`:

```python
string.ascii_lowercase
string.ascii_uppercase
string.punctuation
string.digits
```

В зависимости от выбора пользователя необходимые категории объединяются в общий набор символов, из которого затем создаётся пароль.

##### Генерация символов

Для выбора символов используется модуль `random`.
В отличие от модуля `secrets`, `random` не предназначен для генерации криптографически стойких случайных значений. Из-за этого в теории пароль можно расчитать, но эта программа генерирует пароли оффлайн, что делает очень сложным нахождение точного времени его генерации для расчета.

##### Важное ограничение

Выбранная категория означает, что её символы **разрешено использовать**, но программа не гарантирует присутствие хотя бы одного символа из каждой выбранной категории. Для небольших длин вероятность такого результата выше.

Если потребуется гарантировать присутствие каждой выбранной категории, алгоритм можно расширить: сначала добавлять минимум по одному символу из каждой категории, а оставшуюся часть пароля заполнять случайными символами из общего набора.
